# یادنگار — لیست کارهای شیشه‌ای با یادآور برای ویندوز

برنامهٔ دسکتاپ ویندوز با Electron + React + TypeScript + Tailwind CSS (ساختار shadcn)،
تقویم شمسی شیشه‌ای، فونت وزیرمتن و یادآوری با اعلان خود ویندوز.

## ساخت و نصب (یک بار)

1. **Node.js** نسخهٔ LTS را از [nodejs.org](https://nodejs.org) نصب کنید.
2. پوشه را از حالت فشرده خارج کنید و روی **`setup.bat`** دوبار کلیک کنید.
3. بعد از چند دقیقه پوشهٔ `release` باز می‌شود:
   - `Yadnegar Setup 1.0.0.exe` → نسخهٔ نصبی (پیشنهادی؛ اعلان‌های ویندوز با این نسخه مطمئن‌ترند)
   - `Yadnegar-Portable-1.0.0.exe` → نسخهٔ بدون نصب

> برای اجرای سریع بدون ساخت فایل نصبی: `run-dev.bat`

## امکانات

- تقویم شمسی با نمای **هفتگی / ماهانه**، دکمهٔ «امروز» و نقطه روی روزهایی که کار دارند (نقطهٔ طلایی = کار مهم)
- افزودن کار با Enter، علامت ⭐ برای کار مهم، 🔔 برای تعیین ساعت یادآوری
- ویرایش با دوبار کلیک روی کار، حذف و تیک انجام‌شده، نوار پیشرفت روز
- فیلتر «این روز / مهم‌ها / همه»
- **یادآوری**: اعلان ویندوز + کارت یادآوری داخل برنامه با «انجام شد / ۱۰ دقیقه بعد / یک ساعت بعد»
  - کارهای مهم اعلانِ ماندگار دارند
  - اگر کامپیوتر خاموش بوده، یادآورهای جامانده (تا ۲۴ ساعت) بعد از روشن شدن نمایش داده می‌شوند
- اجرا همراه ویندوز (پنهان در System Tray) و ماندن کنار ساعت هنگام بستن — هر دو از ⚙️ قابل تغییرند
- دکمهٔ 📌 برای «همیشه رو» نگه داشتن پنجره، Ctrl+N برای کار جدید
- چیدمان افقی دسکتاپ: ساعت و تقویم ماهانه سمت راست، نوار یادآورهای پیش رو و لیست کارها در وسط
- داده‌ها در `%APPDATA%\Yadnegar\yadnegar-data.json` ذخیره می‌شوند

## ساختار پروژه

```
electron/main.cjs        پنجره، Tray، ذخیره‌سازی، زمان‌سنج یادآور
electron/preload.cjs     پل امن بین رابط کاربری و ویندوز
src/components/ui/glass-calendar.tsx        کامپوننت GlassCalendar (نسخهٔ شمسی/راست‌چین)
src/components/ui/liquid-weather-glass.tsx  کامپوننت LiquidGlassCard (کارت‌های شیشه‌ای)
src/components/ui/liquid-glass-button.tsx   دکمه‌های شیشه‌ای تیره
src/components/todo/*    لیست کارها، افزودن، یادآور، تنظیمات
src/hooks/use-tasks.ts   منطق داده‌ها
src/lib/utils.ts         تابع cn (shadcn)
src/lib/jalali.ts        ماه‌ها، روزها و اعداد فارسی
components.json          پیکربندی shadcn
```

### چرا `components/ui`؟
CLI شادسی‌ان (`npx shadcn add ...`) کامپوننت‌ها را در `@/components/ui` می‌گذارد و
ایمپورت‌ها (`@/components/ui/...`, `@/lib/utils`) به همین مسیرها وابسته‌اند؛ با این ساختار
می‌توانید هر کامپوننت دیگری از shadcn یا 21st.dev را بدون تغییر مسیر اضافه کنید.

### تغییرات نسبت به کامپوننت اصلی GlassCalendar
- `date-fns` → `date-fns-jalali` (ماه‌ها و روزهای شمسی، شروع هفته از شنبه)
- ساخت روزها با `addDays` به جای `new Date(y, m, d)` میلادی
- زبانه‌های هفتگی/ماهانه واقعاً کار می‌کنند و props جدید: `marks`, `onSettingsClick`, `onAddNote`, `onNewEvent`
- عکس پس‌زمینه از اینترنت حذف و با پس‌زمینهٔ گرادیانی متحرک (آفلاین) جایگزین شد

## به‌روزرسانی خودکار

برنامهٔ نصب‌شده هر ۶ ساعت (و چند ثانیه بعد از اجرا) نسخهٔ جدید را از
[GitHub Releases](https://github.com/damoonartwork/yadnegar/releases) بررسی می‌کند.
وقتی نسخهٔ جدید باشد، در نوار عنوان دکمهٔ «نسخهٔ جدید آمده» ظاهر می‌شود و از
⚙️ ← به‌روزرسانی با یک کلیک دانلود و نصب می‌شود. (نسخهٔ پرتابل خودکار به‌روز نمی‌شود.)

### انتشار نسخهٔ جدید

1. شمارهٔ `version` در `package.json` را بالا ببر (مثلاً `1.4.0` → `1.5.0`).
2. تغییرات را commit کن و یک تگ با همان شماره بساز و push کن:
   ```
   git tag v1.5.0
   git push origin main --tags
   ```
3. GitHub Actions روی ویندوز نصب‌کننده را می‌سازد و در Releases منتشر می‌کند.
   همهٔ کاربران در اجرای بعدی پیام به‌روزرسانی را می‌بینند.

لینک دانلود همیشگی آخرین نسخه برای کاربران جدید:
https://github.com/damoonartwork/yadnegar/releases/latest
